```bash
git clone https://github.com/artem52qwe/MyPythonProject-chaper3006.git
cd MyPythonProject-chaper3006
python main.py
python -m unittest -v

python -m flake8 main.py pricing.py reporting.py test_pricing.py
```

## Assignment materials

Independent solutions for 73 assignments are in `deliverables/<task-id>`. Reports, tested source files, PDFs and editable presentations are included. Screenshots of repository state and captured command transcripts are in `evidence/`.

Jenkins is an isolated educational instance with local-only SMTP. Reviews are self-reviews, not independent approvals. Native memory experiments run under Linux.
