# Система управления проектами — матрица FURPS+

Макаров Артем Александрович · 3427А

## Область
Проекты экспедиций: задачи, участники, сроки и контроль результата. В колонках представлены именно компоненты модели; строки показывают влияние требований на несколько качеств.
| Требование | F | U | R | P | S | + |
|---|---|---|---|---|---|---|
| Создать проект и задачи | ID проекта и владельца | Пошаговая форма | Атомарная запись | p95 ≤ 2 с | Отдельный сервис проекта | API v1 |
| Назначить исполнителя и срок | Проверка участника проекта | Календарь и пояснение ошибки | Проверка версии | 50 пользователей | Тесты переходов | UTC в хранении |
| Отчёт по просроченным | Фильтр по сроку и статусу | Сортировка по важности | Согласованный снимок данных | 5000 строк за 15 с | Независимый модуль отчёта | CSV UTF-8 |
| Восстановить проект | Вернуть состояние по ID | Сообщить период восстановления | RPO 12 ч, RTO 90 мин | Отдельный стенд восстановления | Проверяемая инструкция | Ежедневная копия |

## Вывод
Основные свойства — корректное назначение ответственности и сохранность истории. Быстрый отчёт с неправильными сроками бесполезен. Все числа являются предлагаемыми целями. Приёмка включает конкурентное редактирование, проверку ролей и восстановление копии; фактические измерения ещё не выполнены.
