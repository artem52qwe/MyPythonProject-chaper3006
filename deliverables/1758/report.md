## Сравнительная таблица
| Название инструмента | Платформа | Основные функции | Возможности |
|---|---|---|---|
| Apache NetBeans, IDE | Windows, Linux, macOS при совместимой Java | Редактор, навигация, отладка | Разработка Java-модулей в одном окружении |
| Git, СКВ | Windows, Linux, macOS | История, ветки, merge | Локальная работа и обмен коммитами |
| Eclipse Papyrus, CASE | Веб-версия и настольная среда Eclipse | Модели UML | Визуальное описание структуры и поведения |
| Maven, сборка | Платформы с совместимой Java | POM, зависимости, lifecycle | Единые команды тестирования и упаковки |

## Apache NetBeans
Это интегрированная среда разработки. Она связывает редактирование и отладку. Навигация помогает находить определения. Рефакторинг снижает риск неполного переименования. В учебном проекте среда применяется к Java-клиенту мастерской. Она не заменяет согласование требований.

## Git
Git хранит историю изменений. Коммит фиксирует связанный набор правок. Ветка отделяет эксперимент от основной линии. Слияние объединяет результаты работы. Для мастерской это позволяет проверить изменение тарифа в отдельном PR. Конфликт требует смыслового решения автора.

## Eclipse Papyrus
Papyrus относится к средствам моделирования. Его предметом являются UML и расширения. Модель показывает сущности и взаимодействия. В мастерской диаграмма связывает заказ, операцию и исполнителя. Это помогает обсуждать структуру до реализации. Модель необходимо обновлять вместе с изменениями системы.

## Maven
Maven организует сборку Java-проекта. POM хранит описание проекта и зависимостей. Стандартные стадии делают команды предсказуемыми. Тестирование включается в жизненный цикл сборки. В мастерской Maven упаковывает Java-клиент. Успешная сборка не доказывает правильность бизнес-правил без тестов.

## Сценарий использования
Модель заказа → реализация в IDE → коммит Git → проверка Maven → обсуждение результата. Категории дополняют друг друга; одинаковый интерфейс не делает инструменты взаимозаменяемыми.
