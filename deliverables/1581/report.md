# Пять инструментов для мастерской разработки

Макаров Артем Александрович · 3427А

## Классификация
| Инструмент | Назначение | Основные функции |
|---|---|---|
| Apache NetBeans, IDE | Разработка Java-приложения | Редактор, рефакторинг, отладка |
| Git, распределённая СКВ | История проекта | Коммиты, ветки, сравнение и слияние |
| Eclipse Papyrus, CASE | Моделирование системы | UML-модели, связи и ограничения |
| Maven, сборка | Воспроизводимый Java-проект | Зависимости, стадии сборки, тесты |
| pytest, тестирование | Проверка Python-сервисов | Assertions, fixtures, параметризация |

## Вывод
Инструменты решают разные задачи. Модель описывает структуру, IDE помогает реализовать её, Git сохраняет изменения, сборка повторяет процесс получения результата, тесты проверяют поведение. Для учебной мастерской Python достаточно редактора, Git и pytest; Maven нужен только Java-модулю. Выбор полного набора без связи с языком увеличил бы сопровождение. Пример рабочего процесса: уточнить модель заказа, реализовать расчёт, зафиксировать коммит, выполнить тесты и проверить изменение через PR.
