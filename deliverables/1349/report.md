# Жизненный цикл текстового редактора в мастерской

Макаров Артем Александрович · 3427А

## Введение
Рассматривается жизненный цикл использования редактора Apache NetBeans в учебной мастерской, а не закрытая история разработки продукта. Начальные шаги, эксплуатация, сопровождение и вывод отделены от процессов производителя.
| Этап жизненного цикла | Описание действий |
|---|---|
| Выбор и подготовка | Проверить языки проекта, совместимую Java и ОС; определить необходимые плагины и источник установщика |
| Установка | Скачать с официального сайта, выполнить установку, настроить JDK, открыть учебный проект и проверить запуск |
| Использование | Редактировать код, переходить к определению, запускать тесты и отладчик; изменения хранить в Git |
| Обслуживание | Проверять совместимость обновлений на копии проекта; сохранять настройки, обновлять поддерживаемые компоненты |
| Миграция | Открыть проект в новой среде, проверить сборку и тесты, перенести только необходимые настройки |
| Вывод из эксплуатации | Сохранить исходники и инструкции, проверить восстановление в новой среде, удалить ненужную установку штатным способом |

## Анализ
Установка завершена не фактом появления ярлыка, а успешной сборкой учебного проекта. Во время эксплуатации важна воспроизводимость: команда должна знать используемую Java и команду сборки. Обновление сначала проверяется на копии, чтобы несовместимый плагин не остановил работу. Перед удалением среды исходники должны оставаться независимыми от неё. Git помогает сохранить историю, но сам по себе не архивирует все локальные настройки.
## Вывод
Жизненный цикл включает подготовку замены и проверку сохранности результатов. Описанные действия являются планом, установка или удаление NetBeans в этой работе не выполнялись.
