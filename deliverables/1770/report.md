# Выбор инструментов: сравнительная матрица

Макаров Артем Александрович · 3427А

## Контекст
Учебный проект: Java-клиент мастерской с версионируемыми диаграммами. Оценка удобства — аналитическое суждение, а не пользовательский эксперимент.
| Характеристика | NetBeans | Git | Maven | PlantUML |
|---|---|---|---|---|
| Назначение | IDE | История исходников | Сборка Java | Диаграммы из текста |
| Основные функции | Редактор, debugger | Коммит, ветвление, merge | Зависимости, тесты, пакет | Классы, состояния, последовательности |
| Удобство | Единый интерфейс, нужно освоить проект | Команды требуют понимания истории | Стандартный lifecycle, конфигурация POM | Текст удобно рецензировать, синтаксис нужно выучить |
| Интеграция | Проект и сборка | IDE и CI | IDE и CI | Документация и CI |
| Стоимость | Open source, без обязательной платы за лицензию | Open source | Open source | Open source; условия выбранной сборки проверяются |
| Ограничение | Зависит от языка и плагинов | Не проверяет смысл кода | Не заменяет тестовые сценарии | Не исполняет бизнес-логику |

## Вывод
Победителя между категориями нет. Для проекта они образуют цепочку: диаграмма → реализация → история → сборка. Полная стоимость включает обучение, поддержку и вычислительные ресурсы, поэтому бесплатная лицензия не означает нулевые расходы.
